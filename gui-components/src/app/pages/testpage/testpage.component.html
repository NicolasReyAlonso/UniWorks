Frontend Abstracto

Una arquitectura desacoplada diseñada para aplicaciones empresariales de alta complejidad. Separación total entre lógica de negocio, servicios de datos y representación visual.

ngt-gui/core

El "cerebro" del framework. Gestiona la lógica pura y la comunicación sin depender de la UI.

  • Interfaces de Servicio: Contratos abstractos para Backend y Autenticación.
  • State Management: Gestión del estado global de la aplicación de forma reactiva.
  • Message Log Service: Sistema centralizado de eventos y logs de sistema.
  • Injection Tokens: Desacoplamiento total mediante DI de Angular.

ngt-gui/gui

La capa visual inteligente. Componentes dinámicos que se adaptan a los datos del Core.

  • Dynamic Browser: Listados automáticos basados en configuración de backend.
  • Modal Info Service: Ventanas emergentes programáticas y tipadas.
  • Abstract Components: Clases base para formularios y vistas de detalle.
  • Theming System: Soporte nativo para modos oscuros y personalización visual.

¿Por qué NGT-GUI?

Al separar el Core de la GUI, permitimos que la aplicación escale sin que los cambios en el diseño afecten a la lógica de datos, facilitando el mantenimiento y los tests unitarios.
